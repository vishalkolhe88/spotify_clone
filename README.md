# Spotify Clone

A modern and responsive **Spotify Clone** created to practice front-end web development by recreating the interface of a music streaming platform.

---

## 📖 About

Spotify Clone is a music streaming interface inspired by Spotify's design and layout.

The project includes sections for music, playlists, library, and a music player with a clean dark-themed user interface.

---

## 🎯 Objective

The objective of this project is to practice **HTML5, CSS3, and JavaScript** by building a responsive music streaming website with an interactive and user-friendly interface.

---

## ✨ Features

- 🎵 Spotify-inspired user interface
- 🏠 Home section
- 🔍 Search section
- 📚 Your Library
- 🎧 Music and playlist cards
- ▶️ Music player
- ⏯️ Play and pause controls
- ⏮️ Previous and next controls
- 📱 Responsive design
- 🌙 Modern dark theme
- 🎨 Clean and organized layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3

- Font Awesome

## 🖥️ Website Sections

### 🏠 Home

Displays music, playlists, and recommended content.

### 🔍 Search

Provides a search interface for finding music and content.

### 📚 Your Library

Contains playlists and saved music.

### 🎵 Music Cards

Displays songs, albums, and playlists in an organized layout.

### 🎧 Music Player

Provides music controls such as play, pause, previous, next, and progress controls.

## 📱 Responsive Design

The website is designed to work across:

- 💻 Desktop
- 📱 Mobile
- 📲 Tablet

Responsive CSS techniques and media queries are used to adapt the layout to different screen sizes.

## 🚀 How to Run

1. Clone or download the repository.
2. Open the `Spotify-Clone` folder.
3. Open `index.html` in a web browser.
4. The Spotify Clone website will open.

No additional installation is required.
